# 🏏 IPL Rohit Sharma vs Virat Kohli Analysis

## 📊 Project Overview

This project compares the IPL batting performance of Rohit Sharma and Virat Kohli from 2008 to 2026.

## 🛠️ Tools Used

* Python
* Pandas
* Matplotlib
* Google Colab
* CSV

## 📈 Analysis

In this project, I created:

* Year-wise comparison
* Line chart
* Bar chart
* Pie chart
* Total runs comparison

## 🎯 What I Learned

* Reading CSV files using Pandas
* Working with DataFrames
* Analyzing data
* Creating graphs using Matplotlib
* Data visualization

## 🚀 Project Goal

This project helped me improve my Python, Pandas and Data Visualization skills as part of my journey toward Data Analytics and AI/ML.
